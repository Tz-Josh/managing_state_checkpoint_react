# To-Do List Application

A comprehensive To-Do List application built with React that demonstrates various aspects of state management, form validation, and data persistence.

## Features

- ✅ **Add Tasks**: Create new tasks with name and description
- ✏️ **Edit Tasks**: Update existing task details
- 🗑️ **Delete Tasks**: Remove tasks with confirmation dialog
- ✅ **Complete Tasks**: Mark tasks as completed/uncompleted
- 💾 **Persistent Storage**: Tasks saved in localStorage
- 🔍 **Filter Tasks**: Filter by All, Active, or Completed
- 📊 **Sort Tasks**: Sort by date or name (ascending/descending)
- 📈 **Task Statistics**: View active and completed task counts
- 🎨 **Beautiful UI**: Modern, responsive design with animations

## Technologies Used

- React 18
- React Hooks (useState, useEffect)
- React-Bootstrap
- React Icons
- UUID for unique IDs
- LocalStorage for persistence
- CSS3 with animations
